# Jonas Proença — Site

Versão pronta para deploy no GitHub Pages.

## Arquivos
- `index.html` — site completo
- `.nojekyll` — impede processamento automático do Jekyll
- `robots.txt` — permite indexação por mecanismos de busca

## Publicação no GitHub Pages
1. Crie ou abra um repositório.
2. Envie todos os arquivos deste ZIP para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Salve.
